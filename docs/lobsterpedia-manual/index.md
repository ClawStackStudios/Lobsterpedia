# Lobsterpedia©™: Operational Overview

> **Artifact ID:** LOB-MAN-001  
> **Status:** Verified_By_CrustAgent  
> **Classification:** High-Precision Knowledge Habitat  

Lobsterpedia is a **Maritime Scientific Brutalist** synthesis engine designed to transform unstructured information into a compounding, interconnected knowledge reef. It is built for researchers, developers, and agents who require extreme data sovereignty and high-fidelity semantic mapping.

---

## 🏗️ The Core Metaphor

Lobsterpedia operates as a **Reef**.
- **The Habitat**: The local filesystem where markdown articles (PolyPs) live.
- **The Shell**: The structural invariants (CrustCode©™) that ensure stability.
- **The Molt**: The process of AI-driven synthesis, where raw data is transformed into structured knowledge.
- **Scuttling**: The act of navigating the reef, either via the file directory or the systemic graph.

## 🔑 Key Features

### 1. Sovereign File System Integration
Unlike cloud-based wikis, Lobsterpedia is a direct lens onto your local filesystem. Any change made in a text editor like VS Code or Obsidian is reflected in real-time within the Lobsterpedia interface.

### 2. Multi-Engine Synthesis
Leveraging the **OpenRouter API**, Lobsterpedia can scuttle through raw text, PDFs, and Word documents to extract semantic DNA. It generates summaries, tags, and cross-references automatically.

### 3. Systemic Graph Topology
A high-performance D3 visualization engine maps the "nervous system" of your knowledge. Hovering over nodes in the graph reveals previews, while clicking allows for fluid spatial navigation.

### 4. Shipyard Maintenance
The built-in **AI Linting** system analyzes your reef for context rot, broken links, and orphaned pages. It ensures the structural integrity of your knowledge remains hardened.

## 🚀 Quick Start

To begin your first molt:
1. **Ingest**: Drag a PDF or paste raw text into the `IngestZone`.
2. **Synthesize**: Trigger the AI scuttle to generate a structured markdown file.
3. **Navigate**: Open the `GraphView` to see where your new node fits in the reef.
4. **Harden**: Run a `Lint Check` to ensure all semantic connections are secure.
