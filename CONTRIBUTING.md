# 🦞 Joining the Reef: Contribution Guidelines

To contribute to Lobsterpedia©™, you must adopt the **CrustCode©™** principles and follow the **ClawStack©™** methodology.

## 🧬 The Molt Process
1.  **Initialize your habitat**: Ensure your development environment matches the `package.json` specifications.
2.  **Follow the Feature-First Micro-Architecture**: Never create monolithic components. Partition logic into `shell-core`, `reef-presentation`, or `molt-engine`.
3.  **Sign your work**: Prefer the 🦞 emoji in commit messages and documentation.
4.  **Hardened Logic**: All new code must be type-safe and verified via the `Shipyard` linting protocols.
5.  **Manual Protocol Respect**: Ensure any new automated features respect the `isManualMode` system flag.

## 🛠️ Development Workflow
- `npm run dev`: Launch the internal habitat and scuttle the wiki.
- `npm run lint`: Verify shell integrity via tsc.
- `npm run build`: Prepare the exoskeleton for production.

## 🛡️ Security Protocol
Follow the guidelines in `SECURITY.md`. Never commit sensitive DNA (API keys).
